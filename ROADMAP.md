# Roadmap

Principle: if it does not save time or improve decision making, it does not make the roadmap.

## v0.1 · FinanceOS

Implemented: email authentication UI and finance gating; accounts creation/listing; database-backed imports, normalization, rules, review, dashboard, import history/reversal and audit trail; two-user RLS tests.
Next: complete personal account/browser acceptance testing, account editing, password recovery, actual export adapters, explicit fee splitting, stronger duplicate reconciliation, account balances and reconciliation, audit browsing, saved selection mappings, pagination UX and import error exports.

## v0.2

Clients, projects, invoices/line items, subscriptions, monthly P&L, project profitability and recurring spend. Schema foundations included; workflow implementation remains.

## v0.3

Receipt OCR, bank reconciliation, executive dashboard, cash flow forecasting and accountant-reviewed tax classifications.

## v1.0

Direct account connections where available, organizations and roles, CPA portal, mobile app and optional AI Chief of Staff. Model integration needs separate credentials and agreed data handling.
